# 制拓纸卷动效

`name-paper-motion.js` 导出 `mountPaperRolls(container)`，立即返回 `{ dispose(), metrics() }`，材质异步加载。页面进入时挂载，离开时必须释放，未完成加载的场景在准备完毕时自行释放，避免快速往返出现重复纸卷。

匹配 `button[data-finish-key="paper"][data-finish-id]` 中的 `.paper-visual`，不接管点击或修改选中状态。悬停和键盘焦点独立展开各卷，离开且无焦点时收起；系统减少动态时直接完成目标姿态。静态 PNG 保留至首帧成功，加载失败或 WebGL 上下文丢失时恢复静态回退。

纸面与卷头复用 `design/paper-unroll-motion-20261011/paper-scene.mjs` 的真实薄网格变形：固定上方木轴、向下喂纸、下缘弯曲渐舒展。适当降低网格密度以适合六个 120×264 左右的 UI 纸卷；静止时不持续渲染。动效纹理读自 `assets/name/craft-ui/`，暖灰去饱和参数参照批准稿的 Blender 材质；正式拓片渲染的纹理和效果未由本模块修改。

Three.js 0.186.0 运行时与 MIT 许可随此目录保留。GSAP 使用主网站已经加载的全局版本。

自查涵盖六卷独立性、木轴固定、途中反向、键盘选择、减少动态、上下文丢失回退，以及释放后连续三次重新进入。这里是 UI 动作近似，没有进行纸张力学模拟；浏览器不支持 WebGL 时使用静态展开回退。
