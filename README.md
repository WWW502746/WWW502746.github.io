## 预览

在本目录运行 `node server.mjs`，然后访问 `http://127.0.0.1:4173`。三维展品需要通过本地服务加载，不能直接双击 HTML 文件。

也可双击 `启动碑林本地预览.bat`。启动器会识别并更新本目录仍在运行的旧预览服务，其他目录占用同一端口时会提示错误。V6 预览服务支持视频分段读取和定位，不需要压缩视频。
